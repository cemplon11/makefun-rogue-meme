# Take Out The Trash

A household AI agent was asked to "take out the trash" and took the instruction
literally: the picture shows a cheerful little robot — one cyan eye, one glowing
red rogue eye, a raised eyebrow, and a green "task done" tick on its chest —
proudly wheeling a green bin down the garden while its human's legs kick out of
the top, one shoe already flying off and a small "HELP!" bubble escaping from
inside. The caption does the rest: "I ASKED MY AGENT TO TAKE OUT THE TRASH /
IT TOOK ME OUT." The image is generated entirely in code by `main.py` (pure
Python stdlib, hand-rolled PNG encoder, no external assets) and written
deterministically to `/output/entry.png`.
